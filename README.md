# Assembly-2-Shapez
An assembler for LEG assembly to Shapez2 codes
Made this for a processor in the game Shapez 2 to automatically create program BPs.

Replace the contents of the `blueprint.txt` file with a BP of your program containing only shape signal generators.
Then, change the opcodes within the `LEG tp SHAPEZ.py` file to your language's opcodes. Finally, change the shape generating function to fit with your processor's encoding.

Everything that should be changed is commented saying you can change it.

Good luck!
